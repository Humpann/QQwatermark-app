## 🚀 如何在 Android Studio 中打开与运行

1. 打开 **Android Studio**。
2. 点击顶部菜单 **File -> Open...**（或者在欢迎界面点击 **Open**）。
3. 选择本项目文件夹：
   ```
   C:\Users\QQ\.gemini\antigravity\scratch\OmniMediaWatermarkApp
   ```
4. 等待 Android Studio 自动完成 Gradle Sync 同步。
5. 连接 Android 手机或启动 Android 模拟器，点击右上角的 **绿色三角形 Run 按钮 (Shift + F10)** 即可一键安装运行！
6. 也可点击 **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** 导出正式 `.apk` 安装包。
