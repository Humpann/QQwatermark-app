三、媒体解析核心算法与防风控逆向经验
================================================================================
1. 抖音（Douyin / TikTok）全场景解析流水线：
   - 步骤 1：短链重定向追踪（Redirect Tracing）
     * 针对形如 `https://v.douyin.com/mP3_KTJkjtg/` 的链接，模拟 iOS Safari UA 自动跟随 302 重定向获取真实落地页。
   - 步骤 2：作品 ID 万能提取正则表达式（Regex Pattern）
     * 抖音目前有多种内容形式：普通视频（/video/）、图集（/note/）、实况幻灯片（/slides/）。
     * 关键正则必须覆盖：
       `/(?:video|note|slides|share/video|share/note|share/slides)/(\d+)`
       `modal_id=(\d+)`
       `item_ids=(\d+)`
       `itemId=(\d+)`
       `aweme_id=(\d+)`
       `(\d{18,20})`
   - 步骤 3：多层数据降级抓取（Multi-Tier Data Fetching）
     * 探测点 A: `https://www.iesdouyin.com/share/slides/{id}/`
     * 探测点 B: `https://www.iesdouyin.com/share/video/{id}/`
     * 探测点 C: `https://www.iesdouyin.com/share/note/{id}/`
     * 探测点 D: `https://www.douyin.com/aweme/v1/web/aweme/detail/?aweme_id={id}&aid=6383&device_platform=webapp`
   - 步骤 4：深层 SSR 数据逆向提取
     * 网页源代码中包含 `window._ROUTER_DATA`。
     * 解析 `loaderData` 字典中的各分支：
       - 普通视频分支: `loaderData["video_(id)/page"]["videoInfoRes"]["item_list"][0]`
       - 图集/实况分支: `loaderData["note_(id)/page"]["itemInfo"]["itemStruct"]` 或 `loaderData["itemStruct"]`
   - 步骤 5：无水印媒体直链生成
     * 视频：将播放地址中的 `playwm` 替换为 `play`，并附加 `ratio=1080p` 强制获取最高码率画质。
     * 图集：提取 `images` 数组中的原画大图直链（去掉裁剪参数，替换为最高分辨率 webp/jpeg）。
     * 实况照片（Live Photos）：成对提取图片 (`image_url`) 与动态实况片段 (`video_url`)。

2. 快手（Kuaishou）解析流水线：
   - 追踪 `https://v.kuaishou.com/...` 重定向；
   - 抓取页面中的 `window.INIT_STATE` 或通过 GraphQL 接口获取无水印原画视频及图集。

四、Android 客户端原生架构与关键技术
================================================================================
1. 界面与交互设计（UI/UX）：
   - 1:1 像素级复刻 Apple iOS 18 Liquid Glass 磨砂流体玻璃效果与 Aurora 极光背景。
   - 屏幕顶置操作卡片：输入框与「⚡ 开始 4K 原画解析」高光呼吸按钮置顶，彻底杜绝任何被底部导航栏遮挡的问题。
   - 底部灵动胶囊浮动岛（Dynamic Island Capsule）：
     * 未解析时：显示 `⚡ 开始 4K 解析`；
     * 解析成功后：联动切换为 `⬇ 保存到系统相册`，支持一键批量下载。
   - 内置极客风【实时解析诊断日志 (Live Logs)】抽屉：
     * 点击顶部 `ⓘ` 图标可随时展开/收起；
     * 遇错自动弹发展示，支持一键复制诊断日志，通信全透明。

2. 核心源码文件分工：
   - `OmniMediaWatermarkApp/app/src/main/assets/index.html`:
     * 前端完整 UI，包含 Lucide 图标库、Tailwind CSS、Live Photo 触控动效、日志渲染逻辑。
   - `OmniMediaWatermarkApp/app/src/main/java/com/omnimedia/watermark/MainActivity.kt`:
     * 原生壳层与 WebView 容器，负责权限申请、相册保存（MediaStore API）、系统剪贴板监听。
     * 挂载 `@JavascriptInterface` 供前端调用。
   - `OmniMediaWatermarkApp/app/src/main/java/com/omnimedia/watermark/NativeParser.kt`:
     * 核心多通道调度引擎，基于 Kotlin 协程 `Dispatchers.IO` 执行全异步非阻塞网络调度。

五、踩坑记录与关键技术突破 (Bug Fixes & Lessons Learned)
================================================================================
1. 【踩坑 1：JavaScript 桥接通信特殊字符/换行符静默崩溃】
   - 现象：点击解析后界面无任何反应，Android Studio logcat 报 JavaScript SyntaxError。
   - 根因：抖音作品的标题或作者签名中经常带有回车换行符 `\n` 或双引号 `"`。如果通过字符串模板 `evaluateJavascript("onResult($rawJson)")` 传入，字符串中的物理换行直接破坏了 JS 语法结构。
   - 彻底修复：在原生层将 JSON 序列化为 UTF-8 字节后使用 `Base64` 编码；JS 端通过 `atob` + `TextDecoder('utf-8')` 二进制解包，100% 杜绝任何 emoji、换行、特殊符号转义失败。

2. 【踩坑 2：国内运营商 DNS 污染导致 Vercel 免费域名超时】
   - 现象：手机连接 WiFi 或 4G 时，请求 `q-qwatermark-app.vercel.app` 报错 `SocketTimeoutException 8000ms`。
   - 根因：国内部分 ISP DNS 将 `*.vercel.app` 泛域名污染到了不可达的海外 IP（如 `157.240.21.9`）。
   - 彻底修复：
     * 方案 A: App 端集成阿里云公共 DoH（DNS-over-HTTPS `https://223.5.5.5/resolve`），获取纯净 Anycast IP 绕过污染。
     * 方案 B: 局域网优先探测模式，手机与电脑在同一 WiFi 时自动 0.08 秒极速直连电脑本地服务 (`192.168.1.11:8888`)。

3. 【踩坑 3：抖音 Slides 实况幻灯片缺失 videoInfoRes】
   - 现象：常规视频可解析，但陈泽语录等实况幻灯片提示作品不存在。
   - 根因：抖音对图文幻灯片采用了不同的 SSR 结构，数据位于 `loaderData` 下的 `itemInfo.itemStruct`，必须多层回溯扫描。
